How it Works

When you click "Execute", this dashboard does not send the message directly.

Instead, it executes the independent demo/crash_publisher.py script as a background process. That script acts as a completely separate client: it opens a TCP socket to the broker, handshakes, fires the message, and closes the connection.

Open the Subscriber Hub in another tab to watch the distinct backend subscribers react to the event in real-time.
